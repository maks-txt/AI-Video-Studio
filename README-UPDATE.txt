AI VIDEO STUDIO — БЕСПЛАТНОЕ ОБНОВЛЕНИЕ

В архиве два файла для корня GitHub-репозитория:
- index.html — обновлённое приложение
- sw.js — обновление Service Worker, чтобы браузер быстрее получил новую версию

Как установить:
1. Открой репозиторий GitHub → файл index.html → Edit.
2. Замени содержимое index.html содержимым нового файла из архива и сделай Commit changes.
3. Так же замени sw.js и сделай Commit changes.
4. Подожди публикацию GitHub Pages и открой сайт заново.

Сохранность:
- ключ localStorage av_projects сохранён;
- ID существующих проектов и их статусы не меняются;
- старые заметки сохраняются и показываются в проекте;
- вложенные медиафайлы хранятся отдельно в IndexedDB этого браузера/устройства.

Возможности:
- генератор серий идей 5/10/20/30 по шаблонам;
- перенос выбранной идеи в концепцию;
- сборка черновика сценария;
- автоматическая раскадровка;
- генерация промптов для визуальных сцен;
- браузерная озвучка текста (если поддерживается браузером);
- подготовка и экспорт SRT-субтитров;
- загрузка и скачивание своих изображений, видео и аудио;
- экспорт проекта в TXT и JSON, импорт JSON-резервной копии.

Ограничения:
- генерация идей и сценариев работает локально по шаблонам, это не облачная AI-модель;
- браузерная озвучка зависит от доступных голосов iOS/Safari;
- автоматический рендер готового MP4, платная/облачная AI-генерация и автопубликация не включены.
